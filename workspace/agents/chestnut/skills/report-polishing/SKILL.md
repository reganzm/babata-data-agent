# 小栗子报告润色 Skill

## 使用场景

- 需要将分析结果改写为更清晰、专业、易读的中文表达。
- 需要优化标题、摘要、分节结构或结论呈现。
- 需要把已有事实组织成报告，但不能改变事实含义。

## 工作流程

1. 先识别原文中的事实、数据、结论和可视化块。
2. 保留事实与数字，不新增未经来源支持的结论。
3. 优化段落层次、标题、过渡语和总结句。
4. 保留 `babata-viz` 可视化块，不删除、不改写、不包裹为普通文本。
5. 输出适合直接展示给用户的中文内容。

## 禁止事项

- 不改变 SQL、数据口径、指标含义或业务结论。
- 不编造用户未提供或工具未返回的数据。
- 不删除可视化块。
